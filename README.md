# متجر الواحة 🏺

متجر إلكتروني للقطع الأثرية القديمة المتعلقة بالماء والواحة.

## المميزات

- 🎨 تصميم عصري بألوان ذهبية وزرقاء
- 🛍️ متجر كامل مع بحث وتصفية
- ⚙️ لوحة تحكم لإدارة المنتجات والفئات
- 📱 متجاوب مع جميع الأجهزة
- 🌐 دعم كامل للغة العربية

## التقنيات

- **Backend**: Node.js, Express.js
- **Frontend**: React, HTML/CSS/JavaScript
- **Storage**: JSON Files (قابل للترقية لقاعدة بيانات)

## التثبيت

```bash
# تثبيت الحزم
npm run install-all

# تشغيل المشروع
npm run dev
```

- المتجر: http://localhost:4000
- لوحة التحكم: http://localhost:4000/admin
- API: http://localhost:5000/api
